# TryHackMe - Hands-On Security Labs

Documentation of practical cybersecurity
exercises completed through TryHackMe.

## Focus Areas
- Security Operations and SOC Analysis
- Threat Hunting and Detection Engineering
- Digital Forensics and Incident Response
- Windows and Active Directory Security
- Network Traffic Analysis
- Malware Analysis
- Azure and Cloud Security
- MITRE ATT&CK Techniques

## Lab Documentation

Each completed lab may include:
- Room Name and Objectives
- Tools and Technologies Used
- Attack Techniques Investigated
- Investigation Methodology
- Commands and Queries
- Findings and Lessons Learned
- Defensive Recommendations

## Purpose

Demonstrate hands-on cybersecurity
experience through independently
documented security exercises.
