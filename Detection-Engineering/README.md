# Detection Engineering

Development, testing, and optimization
of security detections across Microsoft
Sentinel and Defender XDR.

## Topics
- Custom Detection Rules
- MITRE ATT&CK Mapping
- Behavioral Detection Logic
- Indicators of Compromise (IOCs)
- False Positive Reduction
- Detection Testing and Validation
- Detection Tuning and Optimization
- Threat-Informed Defense

## Purpose
Build and document original detections
that identify suspicious behavior,
reduce alert fatigue, and improve
security operations.

## Detection Documentation
Each detection will include:
- Detection Objective
- Data Sources
- KQL Query
- MITRE ATT&CK Technique
- Testing Methodology
- Expected Results
- False Positive Considerations
- Recommended Response Actions
