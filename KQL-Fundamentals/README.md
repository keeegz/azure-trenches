# KQL Fundamentals

Hands-on Kusto Query Language (KQL) examples
for security operations, threat hunting,
and detection engineering.

## Topics
- Filtering and Sorting
- Aggregations and Summarization
- Joins and Unions
- Parsing and String Manipulation
- Time-Based Analysis
- Security Investigation Queries

## Purpose
Develop practical KQL skills through
original queries and real-world
security investigation scenarios.
